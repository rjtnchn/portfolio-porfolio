# Personal Portfolio

Personal portfolio site built with React and React Router.

**Live:** https://portfolio-porfolio.vercel.app/

## Stack

- React 19
- React Router 7
- Vite 8
- Deployed on Vercel


## Deployment

Deployed on Vercel. `vercel.json` rewrites all paths to `index.html` so client-side routes (e.g. `/projects/3`) resolve correctly on direct visits and refreshes.
